# AI Class Ledger — ค30202

ระบบจัดการเรียนการสอนรายชั่วโมง เน้น AI + บันทึกคะแนนเรียลไทม์ + ส่งออกเข้า Google Sheet เดิม
ฐานข้อมูล libSQL: ไฟล์ในเครื่องตอนพัฒนา (`data/`), Turso ตอนขึ้นออนไลน์ — Node 22.13+, dependency เดียวคือ `@libsql/client`

```
cd ai-class-ledger
npm install
set TEACHER_PIN=รหัสของครู
set ANTHROPIC_API_KEY=sk-ant-...        (เปิดฟีเจอร์ AI)
set GOOGLE_SA_FILE=C:\path\service-account.json   (เปิด export)
npm start        → http://localhost:3100  (ครู)   /student  (นักเรียน)
```

## ฟีเจอร์
- **ชั่วโมงเรียน**: หัวข้อ/ตัวชี้วัด/เน้น AI, AI สร้างแผน 50 นาที, บันทึกหลังสอน
- **เช็คชื่อ** (/ ส ข โ) · **คะแนน** บันทึกทีละช่อง กระจายทุกเครื่อง (ถามเหตุการณ์ใหม่ทุก 2 วินาที) · **คุณลักษณะ 9 ข้อ** (รวมการใช้ AI อย่างมีจริยธรรม)
- **นักเรียน** (/student, ใช้รหัสส่วนตัว): ดูคะแนน/เวลาเรียน, ส่งงาน, บันทึกการใช้ AI (prompt, วิธีตรวจสอบ, สะท้อนคิด)
- **AI**: ตรวจงานตามรูบริค (เป็นข้อเสนอ ครูต้อง "อนุมัติ" ก่อนลงคะแนน), สรุปห้อง/นักเรียนเสี่ยง
- เกรดที่หน้าจอ = ระหว่างภาค 70 / ปลายภาค 20 / คุณลักษณะ 10 (ตามโครงสร้างรายวิชาในชีท แก้ได้) — ใช้ดูแนวโน้ม ตัวเลขทางการคือที่ชีทคำนวณ ปรับเป็นร้อยจากส่วนที่มีคะแนนแล้ว

## Export ไป Google Sheet (แท็บเดิม)
1. Google Cloud → สร้าง Service Account, เปิด Google Sheets API, ดาวน์โหลดคีย์ .json
2. แชร์ชีทให้อีเมลของ service account สิทธิ์ **Editor**
3. ตั้ง `GOOGLE_SA_FILE` (และ `SHEET_ID` ถ้าใช้ชีทอื่น) · `AUTO_EXPORT=1` = ส่งออกเองหลังแก้ไข 15 วินาที
4. ในหน้าครู → นักเรียน → "ดึงรายชื่อจากชีท" เพื่อให้เลขประจำตัวตรงกับแท็บ Grades

ระบบเขียนเฉพาะ **ช่องกรอก** (ไม่แตะสูตร ชีทคำนวณยอดรวมหน่วย/เกรดเอง) และจับคู่นักเรียนด้วยเลขประจำตัว:

| ข้อมูลในระบบ | ลงที่ |
|---|---|
| งานระหว่างภาค (เลือกหน่วย 1–6 + ด้าน K/P/A) | Grades ช่องกรอกตามหน่วย: K = 5 ช่อง, P = 5 ช่อง, A = 2 ช่อง ต่อหน่วย; คะแนนเต็มลงแถว 5 |
| สอบปลายภาค / คุณลักษณะ / บูรณาการ | Grades คอลัมน์ DB / CZ / CY (รวมเป็นคะแนนตามน้ำหนักที่ตั้ง) |
| เช็คชื่อ (/ S ขาด, A ลา, L สาย) | Class Attendance คอลัมน์ตามเลขชั่วโมง (ชม.1 = E … ชม.84 = CJ), วันที่ลงแถว 4 |
| การอ่าน/คิด/เขียน + 9 คุณลักษณะ | Desirable Characteristics คอลัมน์ E–G และ J–R |
| บันทึกการใช้ AI | แท็บใหม่ "ระบบ-บันทึกการใช้AI" (ชีทเดิมไม่มีที่เก็บ) |

ก่อนส่งจริงกด "ดูตัวอย่าง" เพื่อดูว่างานไหนไปคอลัมน์ไหน และนักเรียนคนไหนจับคู่ไม่ได้ ค่าที่ระบบไม่มี (ช่องว่าง) จะไม่ถูกเขียนทับ
ไม่ส่งออก: Teaching Record และ Lesson Plan (มีเมนูเลือก/รูปแบบรายสัปดาห์ของโรงเรียน)

## Deploy บน Vercel (+ Turso)
Vercel ไม่มีดิสก์ถาวรและไม่ค้างการเชื่อมต่อ จึงใช้ Turso (SQLite ออนไลน์) เก็บข้อมูล และเรียลไทม์ใช้การถามเหตุการณ์ใหม่ทุก 2 วินาที
1. **Turso**: สมัคร https://turso.tech → สร้างฐานข้อมูล → คัดลอก URL (`libsql://...`) และสร้าง token
2. **Vercel**: Import repo นี้ → ตั้ง **Root Directory = `ai-class-ledger`** (ไม่ต้องตั้ง build command)
3. ตั้ง Environment Variables:
   - `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`
   - `TEACHER_PIN` (6 ตัวขึ้นไป — ไม่ใช่ 1234), `SESSION_SECRET` (สตริงสุ่มยาวๆ), `NODE_ENV=production`
   - `ANTHROPIC_API_KEY` (ถ้าใช้ AI), `GOOGLE_SA_JSON` (เนื้อไฟล์ service account ทั้งก้อน), `AUTO_EXPORT=1` (ถ้าอยากให้ส่งออกเอง)
4. Deploy → เปิดลิงก์ที่ได้ ส่ง `/student` ให้นักเรียน
ข้อจำกัดบน serverless: `AUTO_EXPORT` ทำงานจากหน้าครูที่เปิดอยู่ (ส่งออก 15 วินาทีหลังมีการแก้ไข) ไม่ใช่จากเซิร์ฟเวอร์ และตัวจำกัดการเดา PIN นับต่อ instance
ใส่ข้อมูลทดลองลงฐานออนไลน์: `TURSO_DATABASE_URL=... TURSO_AUTH_TOKEN=... node seed-demo.js`

ทดสอบ: `npm test`
