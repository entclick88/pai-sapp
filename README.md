# 📚 บทเรียนเกี่ยวกับภาษี (Tax Education Lesson)

บทเรียนแบบ Interactive สำหรับนักเรียนมัธยมปลายเกี่ยวกับภาษี ระยะเวลา 2 ชั่วโมง

## ✨ ฟีเจอร์หลัก

- 📖 **เนื้อหาครบถ้วน** - 7 หัวข้อหลักจากบทนำจนถึงการคำนวณ
- 🧮 **เครื่องคำนวณภาษี** - คำนวณภาษีเงินได้และ VAT แบบ interactive
- 🎨 **ออกแบบสวยงาม** - UI ที่เพราะตา พร้อม gradient และ animation
- 📱 **Responsive Design** - ใช้ได้บนอุปกรณ์ทั้งหมด
- ⏱️ **จัดแบ่งเวลา** - แต่ละหัวข้อมีระยะเวลาสอนที่ชัดเจน

## 📚 เนื้อหาบทเรียน

1. **บทนำ** (30 นาที)
   - จุดประสงค์การเรียนรู้
   - ภาพรวมของบทเรียน

2. **ความหมายของภาษี** (25 นาที)
   - นิยามภาษี
   - ลักษณะสำคัญ
   - ข้อแตกต่างจากค่าธรรมเนียม

3. **ความสำคัญของภาษี** (20 นาที)
   - ความสำคัญต่อประเทศ
   - ประโยชน์ต่อประชาชน
   - ตัวอย่างในชีวิตประจำวัน

4. **ประเภทของภาษี** (20 นาที)
   - ภาษีโดยตรง (Direct Tax)
   - ภาษีโดยอ้อม (Indirect Tax)
   - ตารางเปรียบเทียบ

5. **การเสียภาษี** (25 นาที)
   - กระบวนการเสียภาษีเงินได้
   - อัตราภาษีปัจจุบัน
   - Timeline การยื่นแบบปกติ

6. **ความถูกต้องเกี่ยวกับภาษี** (25 นาที)
   - หลักการปฏิบัติให้ถูกต้อง
   - การเก็บรักษาเอกสาร
   - ผลของการไม่เสียภาษี

7. **เครื่องคำนวณภาษี** (20 นาที)
   - คำนวณภาษีเงินได้บุคคล
   - คำนวณ VAT
   - ตัวอย่างการใช้งาน


   - สามารถเปิดผ่านเบราว์เซอร์ใดๆ (Chrome, Firefox, Safari, Edge)
   - ไม่ต้องติดตั้งอะไรเพิ่มเติม

3. **นำไปสอนในชั้นเรียน**
   - โปรเจคตอร์แสดงเนื้อหา
   - นักเรียนใช้อุปกรณ์ของตัวเอง
   - ใช้เครื่องคำนวณเพื่อฝึกหัด

## 💡 เนื้อหากระบบการภาษีไทย

บทเรียนนี้ใช้ข้อมูลจาก:
- 📋 กฎหมายภาษีอากรประเทศไทย
- 💼 สำนักสรรพากรกรมสรรพากร
- 📊 อัตราภาษีปัจจุบัน (ปี 2566)

## 📖 อัตราภาษีเงินได้ปัจจุบัน

| รายได้ (บาท) | อัตราภาษี |
|------------|---------|
| 0 - 150,000 | ปลอดภาษี |
| 150,001 - 300,000 | 5% |
| 300,001 - 500,000 | 10% |
| 500,001 - 750,000 | 15% |
| 750,001 - 1,000,000 | 20% |
| 1,000,001 - 2,000,000 | 25% |
| 2,000,001 - 5,000,000 | 30% |
| มากกว่า 5,000,000 | 35% |

*หมายเหตุ: อัตราอาจมีการเปลี่ยนแปลง ตรวจสอบกับสำนักสรรพากรเพื่อความแน่นอน*

## 🛠️ เครื่องคำนวณภาษี

### ฟีเจอร์
- ✅ คำนวณภาษีเงินได้ด้วยอัตราแบบขั้นบันได
- ✅ คำนวณ VAT (ภาษีมูลค่าเพิ่ม)
- ✅ รองรับการลดหย่อน
- ✅ ผลลัพธ์แสดงจำนวนเต็มที่ถูกต้อง

### ตัวอย่างการใช้
```
รายได้รวม: 600,000 บาท
ลบ: ค่าใช้สอย: 100,000 บาท
รายได้สุทธิ: 500,000 บาท

ภาษี:
- 0 - 150,000: 0 บาท
- 150,001 - 300,000: 7,500 บาท
- 300,001 - 500,000: 20,000 บาท

รวมภาษี: 27,500 บาท
```
